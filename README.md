## Featured

### Fabler
**Aesop's fables for kids, illustrated by AI and read aloud.** [fable-friends.com](https://fable-friends.com)

`React` `Vite` `Expo` `FastAPI` `RAG`

- Built because my own kids' fable books weren't very child-friendly, and I missed the moral science classes I grew up with.
- Tap-only, no ads, no tracking, and no accounts, so kids can use it alone and no personal data is collected.
- Illustrated with Gemini, narrated with Speechify, with a child-safe RAG chat mode over public-domain stories from Project Gutenberg.
- My niece was the first user. She kept asking to read along.

### CineLens
**A conversational movie intelligence agent.**

`MCP` `SSE` `TMDB API`

- Provider-agnostic orchestrator, so the underlying model can be swapped without touching the app.
- Middleware that enforces prerequisites before tools run, plus an MCP server exposing the TMDB API.
- Fully clickable UI with results streamed over SSE.
- Next up: bring-your-own-key support and an open-source release of the MCP layer.

---

### MindMeet
**UIL Number Sense prep, built from years of volunteering at Texas Math & Science competitions.**

`Full-stack` `LLM pipelines` `Human-in-the-loop`

- Started when I was printing and grading practice sheets for my own kids.
- A data pipeline tags every problem by pattern and by difficulty, because difficulty varies a lot inside a single pattern.
- AI generates problems, and a human review step verifies the solutions before they reach students.
- Goal: adaptive practice for K-12 students.
